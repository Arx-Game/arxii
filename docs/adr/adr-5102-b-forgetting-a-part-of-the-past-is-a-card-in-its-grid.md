# ADR-5102-B: Forgetting a part of the past is a card in its grid, not a mark on the stage

The life page's per-stage Unknown checkbox (#4874), which set `unknown` on every beat of a stage in one save, is gone. Every section's grid now ends on an **Amnesiac** card drawn like the distinction cards around it (`ChapterOffers`' `trailing` slot): no cost, named by the staff copy row `life_amnesiac_name` and read by `life_amnesiac_text`. Picking it sets that one beat's existing `unknown` state, so the server drops the beat's picks and closes its other cards, and the grid shows the Amnesiac card alone until a second click takes it back. A stage every one of whose beats is unknown still reads Unknown and still lists its sections, so each card can be undone. The owner ruled it on 2026-11-12: the checkbox, sitting apart from the cards, "would just confuse players"; forgetting belongs "in the list of the other distinctions as a final option", one section at a time, with text he writes saying the player skips the rest of the step. We rejected making Amnesiac a real `Distinction` with `DistinctionOffer` rows on every beat: a held distinction reaches the sheet as a trait and the background as a pick, and it would not blank the section without special-case code that recognises it, so the card would claim to be one thing and do another. We rejected keeping the stage-wide reach (one card blanking a whole stage): the owner chose one section. No model, migration or server rule changes; `unknown` per beat already existed.
