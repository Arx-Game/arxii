# ADR-4457-A: Magic skills are trained, never bought at character creation

Before this, a Tradition gave no skill content, so a schooled character and a self-taught one started with the same Magic skills and either could buy them with ordinary CG skill points. We decided the only creation source of a Magic skill is the schooling stance picked under Tradition Training: `SchoolingLine.magic_skill_floor` (a column on the stance row, 0 on rank 0) lifts every active Magic-category skill to that value at finalize, and the skills step and `get_skill_allocation_errors` refuse CG points in a Magic skill or one of its specializations. A living Tradition opens stances 0 to 2, an orphaned one 0 and 1, a self-taught one none (`SCHOOLING_MAX_RANK_BY_STATE`); a character without the floor catches up in play, by use, weekly training, or an Academy skill course (`SKILL_COURSE`, enrolled once for coin and a Golden Hare, then rolled sessions), and pays the same price as anyone else (no Unbound surcharge on a course). We rejected: spending CG points on Magic skills, because the gap between schooled and self-taught could then never exist; a points pool the player spends across Magic skills, where we chose one uniform floor so a stance means one level for every Magic skill; Magic skills free with Tradition membership, where we chose to pay through the stance so the player's Tradition Training rank is what buys the level; a per-Tradition table of skills and levels now, deferred because the set is every Magic-category skill and staff control it by category; a second `DistinctionEffect` on a modifier target found by its `name`, because a row must say what it is by a field, never by its name (#3676), and the builder's linear per-rank value could not hold a rank 1 floor of 20 under a cap of 30; and a floor weighted toward the Path's technique skill, which would make one Tradition train differently by Path instead of by stance.
