# ADR-4889: A face portrait is a private copy in an opaque folder and counts against storage

A mask or alternate self needs a portrait its player chose, and a stranger who sees it must be able to learn nothing about who wears it. The player's own pictures live under `player_<account number>/` in Cloudinary, and a delivery URL carries that path, so a mask that pointed at a gallery picture would carry the same player number as the real face. Copying the picture removes the link: a pick is stored as a new file under one fixed folder, `faces/`, with a blank title, no artist and no gallery link, so its URL, its media row and its path match nothing of the player's. The copy costs the player what its source costs, because it is a stored file: every pick and every upload for a face goes through one shared check, `enforce_player_media_limits`, and `upload_image` and `copy_image` take a row lock on the player first, so two uploads at once cannot both pass the quota. A copy is checked again with the size Cloudinary reports, and destroyed and refused if that passes the cap.

A face with no portrait shows one placeholder for everyone, staff's chosen picture or a built-in grey silhouette, so a mask never shows the real face, a letter that names its wearer, or a broken image. A mask's description is one text on `Persona`, with no history, replacing the real prose only for a viewer who has not seen through the face; the real description keeps its own rules.

**Consequences.** A player who picks an 8 MB picture uses 8 MB more storage. A face portrait copy is not in any gallery and `MediaViewSet` never lists or deletes it, so it leaves only when the face's portrait is replaced or removed (a copy staff authored or another face still wears is never deleted). The sheet payload withholds the real portrait, looks, friend flag and home from a viewer of a mask or a worn alternate self.

**Rejected:** linking the original file (the URL ties the mask to the player); a separate quota for face copies (a second number to tune and a way to store more than the cap); a letter avatar for a portraitless mask (an alternate self keeps the character's own name, so the initial leaks it); a mask description on the guise `Profile` (versioned, but it would add a field to every true profile and to staff edit mode); a per-viewer portrait (one picture for everyone is the ruling).
