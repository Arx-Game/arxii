# ADR-5002: A casting style carries its magic skill

A cast's skill was set on the Path (`Path.technique_skill`, chosen per technique by its own Paths, ADR-4555-A) and the Gift (`Gift.technique_skill`, Minor Gifts only), while the same cast's manner came from the casting style (`Path.style`, ADR-0167, overridden by `Gift.style`, ADR-0199), so staff authored each pairing twice and the two could disagree for a crossed technique. The owner ruled that the style and its skill are one thing seen from two sides (how a character works magic, and how good they are at it), so `TechniqueStyle.skill` now carries the skill and a cast adds the technique's own skill, else the skill of the style it is worked in: the Gift's own style, else the caster's current Path style, the same rule cast concealment reads (`world/magic/services/casting_style.py`). That retires the skill half of ADR-4555-A (a technique cast after a Crossing adds the current style's skill) and gives a Minor Gift with no style the Path style's skill, where it had none. The old fields were dropped with no data migration, a deliberate discard signed off by the owner (ADR-0237): production held one Path value and no Gift values. We rejected keeping the skill on the technique's own Path (it keeps #4555's behaviour but lets the manner and the skill disagree), and keeping a separate Gift skill (two places would still say which skill a cast adds).

> Status: accepted · Source: issue #5002, owner rulings 2026-11-07; verify against `src/world/magic/models/techniques.py` (`TechniqueStyle.skill`), `src/world/magic/services/casting_style.py` and `src/world/magic/services/magic_skills.py` (`_skill_for_path`, `technique_skill_term`). Extends ADR-0167 and ADR-0199; supersedes the cast-skill half of ADR-4555-A and the Path/Gift picker names in ADR-4450.
