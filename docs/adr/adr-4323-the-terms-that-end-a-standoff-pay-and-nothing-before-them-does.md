# The terms that end a standoff pay, and nothing before them does

A standoff is mostly a way for characters to create situations and affect others, so how it ends should shape the ending character's resonance and name, but a press that pays each time would be farmed. The owner ruled on 2026-11-20 that only the act that ends the standoff pays: the terms whose acceptance settles the last live group (a press, a read, an earlier group's terms and a fight that breaks out pay nothing). What it pays is graded by that terms check's result tier through `StandoffEndingAward`, an `OutcomeTierAward` whose row names the `DramaticMomentType` the ending counts as at that result, so `create_dramatic_moment_tag` pays the character's own resonance and renown (staff tune the amounts on the moment type, code holds none) and a witnessed ending also writes a legend deed carrying the terms' archetypes, which is the archetype the faction rules already read. The same ending is one social act fed to the existing kindling path (`award_kindled_deeds`), read with no combat round so the standoff counts as a negotiation as its own rolls do; nothing names a covenant or a Cynosure, so what another character lays on the band (a press whose approach lays a feeling condition) is what makes a covenant's resonance kindle. **Rejected:** paying each approach that lands (a long press farms it, and an approach has no ending to grade), a flat amount per approach or per terms (the roll and the character would not matter), a new kindling mechanism or Cynosure rule (the situations staff already author reach this act), and a second witness definition (the scene list, `scene_witness_personas`, is the one legend uses, here counting only characters another account plays). Two characters one account plays pay each other nothing, and a result with no table row pays nothing. The room's credit line names only the name and the deed, because the resonance that grew may be one nobody has been told of; the actor reads it privately. The deed's `legend_value` is a flat authored worth per result and carries station 0, so a standoff ending is legend for fame and spread and never advances a level (advancement needs a priced stakes contract, ADR-0249); a spent per-scene cap on the moment type pays nothing, a deed included.
