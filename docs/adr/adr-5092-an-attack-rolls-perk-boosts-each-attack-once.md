# ADR-5092: An "attack rolls" perk boosts each attack once, from the roll's caller

A covenant vow's check-bonus situational perk can be limited to attack rolls (`VowSituationalPerk.roll_kind`, "Applies to: Attack rolls"), between "any check", which also boosts dodges, and one check type, which misses holders whose techniques roll other cast checks (owner, 2026-11-12: "more specific than 'any technique' but more broad than 'any check'"; then widened to every attack). It boosts each attack on an opponent once: a plain Strike's hit roll, an attack technique's roll (a cast at an opponent, a joust pass), and an enchanted Strike's technique roll. An enchanted Strike's hit roll does not take it, so a technique carried into a Strike never earns a second boost. This amends ADR-5026's counted-once table by one line: the technique roll now carries attack-rolls perks, and only those; an unscoped or check-type perk and every outcome guarantee (TIER_FLOOR, BOTCH_IMMUNITY) stay on the hit roll (`SituationContext.roll_kind_perks_only`). Which roll is an attack is said by the roll's caller, from what it already knows (`is_attack_on_opponent`, the same test intensity's to-hit bonus uses), carried on `SituationContext.roll_kind` and matched in `perk_scope_matches` like `battle_action_kind`. We rejected a boolean flag (a choice leaves room for later roll kinds), scoping by the technique's category or function tags (they describe the technique, not how this roll is used: a hold cast at an enemy is an attack, an attack-tagged technique used on oneself is not), boosting the enchanted Strike's hit roll instead (a carried technique would then make the sword land more easily while a plain Strike's boost is the same), and giving the technique roll every perk (an "any check" perk would then count twice on one attack).
