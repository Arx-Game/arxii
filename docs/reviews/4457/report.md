## Findings outside this change

None of these is in the #4457 diff, and none changed a result above, but each stops a real player, so they are recorded for the maintainer.

1. A character made through character creation cannot be played. All three approved characters carried Evennia's default lock `puppet:pperm(Developer)`; logging in as their players said "You don't have permission to puppet 'Corvane Fatui'.", and the owner's sheet API returned no stats or skills. The character is created by `create_character_with_sheet` (called at src/world/character_creation/services.py:245), which never calls `ensure_playable_lock` (src/world/roster/services/staff_characters.py:59), the fix #4418 applied to staff-minted characters only. For this pass the lock was set with that function in the scratch database.
2. Production content cannot finish character creation: no Technique in the production dump has an action_template, so `get_gift_options` offers no gift under any Tradition and Path. For this pass staff set the "Technique Cast" template on Grave Bolt and Ice Dart in the stock admin.
3. The production "Technique Cast" check type already weights occult, so a Path whose technique skill is occult counts that skill twice in a cast. This is staff tuning, from #4450.
